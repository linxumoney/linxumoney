我把真实工作里沉淀的流程、判断和工具，整理成 AI 可以直接使用的 Skills。

这里的每个项目都从一个具体任务出发：

- 内容创作：找到选题、写出有声音的内容、搭建演示叙事
- 营销增长：理解用户、写广告、做投放和增长实验
- 产品开发：把模糊想法变成产品决策与可验收的需求
- 研究决策：核验引用、读财报、追踪趋势和市场信号
- 个人成长：岗位匹配、沟通表达与个人工作流
